## ملاحظة سلامة مهمة
سلسلة SQL داخل `onUpgrade` هي:
`DROP TABLE IF EXISTS nabeel_table`

هذا يعني أن ترقية قاعدة البيانات بالطريقة الحالية قد تحذف الجدول القديم. لذلك لا يجوز رفع رقم إصدار قاعدة البيانات دون مراجعة منطق `onUpgrade` واستبداله بترحيل غير هدّام. يجب أن يبقى جدول البيانات القديم كما هو عند إضافة جدول صور منفصل.

## التصميم المقترح — غير مطبّق بعد
بعد التأكد من أن `nabeel_table.ID` هو معرّف السجل الذي يمثل السؤال، يمكن إضافة جدول مستقل للصور، مثلاً:
```sql
CREATE TABLE IF NOT EXISTS question_images (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    record_id INTEGER NOT NULL,
    image_path TEXT NOT NULL,
    sort_order INTEGER NOT NULL DEFAULT 0,
    created_at INTEGER NOT NULL,
    FOREIGN KEY(record_id) REFERENCES nabeel_table(ID) ON DELETE CASCADE
);
CREATE INDEX IF NOT EXISTS idx_question_images_record
ON question_images(record_id, sort_order);
```
استخدام جدول منفصل يحافظ على الأعمدة `N1` إلى `N10` وعلى السجلات القديمة. لكن اسم `record_id` مقصود مؤقتاً؛ لم يتم إثبات دلالة `ID` كسؤال منفرد حتى الآن.
