# خطة التنفيذ وحالة ميزة الصور المتعددة

## النطاق الحالي
- اختيار عدة صور من المعرض.
- التقاط صورة بواسطة تطبيق كاميرا النظام عبر FileProvider.
- نسخ الصور إلى التخزين الداخلي وربط المسارات بالسؤال.
- معاينة الصور وحذف صورة واحدة قبل الحفظ.
- استعادة الصور عند تحرير السؤال.
- عرض الصور في محولي الصفحة الأولى والثانية وإدراجها في PDF.

## حماية البيانات
- `images` حقل اختياري داخل HashMap السؤال؛ غيابه في الأسئلة القديمة يعني قائمة فارغة.
- حذف ملفات الصور المؤكدة مؤجل حتى نجاح `SharedPreferences.commit()`.
- الرجوع دون حفظ ينظف الملفات الجديدة فقط، ولا يحذف الصور الأصلية.
- لا تعديل على SQLite أو `onUpgrade()`.

## تحقق ساكن
- تم تطبيق Patch على نسخة مفككة من APK.
- نجحت فحوص Python للربط والحفظ والإلغاء ومحولي الصفحتين ورسم صفحتي PDF.
- نجح تطبيق Patch مرتين دون تكرار نقاط الربط.

## المتبقي قبل التسليم
1. نجاح GitHub Actions لبناء APK من آخر commit.
2. تجربة المعرض والكاميرا على جهاز حقيقي.
3. اختبار تحرير سؤال قديم وحذف صورة ثم إلغاء التعديل.
4. اختبار PDF والطباعة بصور متعددة وعلى الصفحتين، والتحقق من عدم قص الصور أو تجاوز الصفحة.
5. إعداد توقيع إصدار ثابت إذا أريد تثبيت APK كتحديث فوق النسخة الأصلية.

لا يُدمج فرع العمل إلى `main` قبل استكمال الاختبارات السابقة.
