# محرر الامتحانات 25 — فرع تطوير صور الأسئلة

هذا الفرع مخصص لتنفيذ إرفاق صور متعددة بكل سؤال مع الحفاظ على توافق الأسئلة القديمة.

ابدأ بقراءة [تقرير الفحص والتنفيذ](reports/image-questions-implementation-ar.md).

## النطاق المعتمد
**المعرض فقط.** تم استبعاد الكاميرا من نطاق هذه الميزة حتى لا تعيق الإنجاز.
- اختيار عدة صور في المرة الواحدة من معرض/منتقي صور Android.
- معاينة الصور وإزالة صورة منفردة قبل الحفظ.
- نسخ الصور المختارة إلى التخزين الداخلي للتطبيق، وعدم الاعتماد على URI مؤقت.
- ربط مسارات الصور بالسؤال الصحيح واستعادتها عند تحريره.
- عرض الصور في ورقة الامتحان وإدراجها في PDF.

## الوضع الحالي
- المصدر الأصلي محفوظ في `original/`.
- عملية التفكيك موجودة في GitHub Actions.
- فرع العمل `work/multi-image-questions` منفصل عن `main`.
- تم فحص آلية حفظ الأسئلة عبر Gson وSharedPreferences، وآلية رسم PDF.
- لم تنفذ واجهة الصور أو منطق حفظها بعد، ولم ينتج APK معدل بعد.

## قواعد سلامة البيانات
لا ترفع إصدار SQLite ولا تغير `DatabaseHelper.onUpgrade()` قبل اختبار أثره؛ إذ يحتوي المسار الحالي على DROP TABLE لجدول `nabeel_table`. يجب أن تتعامل الشيفرة الجديدة مع غياب مفتاح `images` في الأسئلة القديمة كقائمة فارغة.

## خطة التنفيذ
1. منتقي صور متعدد من المعرض.
2. نسخ الصور إلى مساحة التطبيق الداخلية.
3. معاينة الصور وحذف صورة منفردة.
4. حفظ المسارات واستعادتها عند تحرير السؤال.
5. إظهار الصور في الامتحان وPDF.
6. بناء APK واختبار التوافق والصفحات الطويلة.
