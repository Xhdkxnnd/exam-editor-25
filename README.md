# محرر الامتحانات 25 — فرع تطوير صور الأسئلة

هذا الفرع مخصص لتنفيذ ميزة إرفاق صور متعددة بكل سؤال مع الحفاظ على توافق الأسئلة القديمة.

ابدأ بقراءة [تقرير الفحص والتنفيذ](reports/image-questions-implementation-ar.md).

## الوضع الحالي
- المصدر الأصلي محفوظ في `original/`.
- عملية التفكيك موجودة في GitHub Actions.
- فرع العمل `work/multi-image-questions` أُنشئ دون تغيير `main`.
- تم فحص آلية حفظ الأسئلة عبر Gson وSharedPreferences، وآلية رسم PDF.
- لم تنفذ واجهة الصور بعد ولم ينتج APK معدل بعد.

## قواعد سلامة البيانات
لا ترفع إصدار SQLite ولا تغير `DatabaseHelper.onUpgrade()` قبل اختبار أثره؛ إذ يحتوي المسار الحالي على DROP TABLE لجدول `nabeel_table`. يجب أن تتعامل الشيفرة الجديدة مع غياب مفتاح `images` في الأسئلة القديمة كقائمة فارغة.

## الهدف
منتقي متعدد، كاميرا، نسخ الصور إلى التخزين الداخلي، معاينة وحذف، استعادة عند التحرير، عرض في الامتحان، وطباعتها في PDF.
