## متابعة 25 نوفمبر 2026 — حماية الصور المحفوظة عند انقطاع التطبيق

- اكتشفت نافذة تعطل دقيقة: قد ينجح حفظ السؤال في SharedPreferences ثم يتوقف التطبيق قبل تنفيذ `finishSave()`. في هذه الحالة يبقى سجل `createdPaths` المؤقت. عند إعادة فتح السؤال ثم إلغاء التحرير، كان `discard()` يحذف كل الملفات في السجل، بما فيها الصور التي أصبحت محفوظة فعلياً ومشاراً إليها من السؤال.
- أصلحت الاستعادة بحيث تُقرأ `images` من خريطة السؤال حتى عند إنشاء سؤال جديد، وأصبح `discard()` يتجاوز أي مسار موجود بالفعل ضمن `originalPaths`. بذلك لا يحذف مساراً مرجعياً إذا بقي سجل مؤقت بعد نجاح الحفظ.
- جعلت `savePending()` يعيد نتيجة `commit()`. إذا فشل حفظ الحالة المؤقتة، تتراجع عملية الاستيراد وتحذف النسخة الجديدة غير المسجلة، أو يُعاد مسار الصورة إلى المعاينة عند فشل حفظ عملية الحذف؛ فلا تُعلن العملية نجاحاً بينما لا يمكن استعادتها بعد إعادة إنشاء Activity.
- أضيفت فحوص ساكنة لهذه الحالات: الاستعادة بعد commit ناجح قبل تنظيف السجل، فشل كتابة الحالة المؤقتة في المعرض والكاميرا، وفشل حفظ حذف صورة من المعاينة.
- لم يتغير مخطط SQLite أو `DatabaseHelper.onUpgrade()`، ولم يُعدّل `main`.
- **حالة التحقق:** لا أعتبر APK مبنياً حتى تظهر نتيجة GitHub Actions لهذا التغيير. كما يبقى اختبار الهاتف الفعلي مطلوباً.

## النطاق المنفذ
- اختيار عدة صور من منتقي Android.
- التقاط صورة بواسطة تطبيق الكاميرا الخارجي عبر `FileProvider`، مع حفظ مسار الملف المؤقت لاستعادته إذا أعاد Android إنشاء الشاشة أثناء التصوير.
- حصر `FileProvider` في مجلد صور التطبيق `Android/data/.../files/Pictures/` بدلاً من كشف جذر التخزين الخارجي.
- نسخ الصور إلى مجلد التطبيق الداخلي `question_images/`.
- تدوير صور JPEG وفق زاوية EXIF المعروفة لدى التطبيق قبل عرضها في المعاينة والامتحان وPDF، دون تعديل الملف الأصلي.
- تخزين المسارات النسبية في المفتاح الاختياري `images` داخل HashMap السؤال.
- معاينة الصور وحذف صورة منفردة قبل اعتماد التغييرات.
- تتبع جميع الملفات الجديدة المستوردة في `createdPaths` مستقلة عن الصور المختارة حالياً، مع حفظ سجلها المؤقت لاستعادته بعد إعادة إنشاء الشاشة؛ بعد نجاح `SharedPreferences.commit()` تُحذف الملفات المستوردة التي أزيلت من المعاينة، وعند الرجوع تُحذف كل ملفات الجلسة الجديدة دون المساس بصور السؤال الأصلية.
- عرض الصور في محول الصفحة الأولى والصفحة الثانية، ورسم صفحتي PDF إلى صور نقطية.

## التوافق وسلامة البيانات
- لا تعديل على مخطط SQLite أو إصدار قاعدة البيانات أو `DatabaseHelper.onUpgrade()`.
- السؤال القديم الذي لا يحتوي `images` يعامل كأنه يحتوي قائمة فارغة.
- لا يُحذف ملف صورة محفوظ عند حذفها من المعاينة؛ يتم الحذف بعد نجاح حفظ السؤال فقط.
