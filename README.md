# محرر الامتحانات 25 — مرحلة التفكيك

هذه الحزمة هي **مرحلة تمهيدية لاستخراج الشيفرة الأصلية** وليست نسخة معدلة من التطبيق.

## المحتويات
- `original/محرر الامتحانات25.apk`: ملف APK الذي رفعه المستخدم.
- `reports/تقرير_الفحص_الأولي.md`: نتائج الفحص الأولي الفعلية.
- `.github/workflows/decompile.yml`: GitHub Actions لتفكيك APK باستخدام APKTool وJADX.

## تشغيل التفكيك على GitHub
1. أنشئ مستودع GitHub جديداً.
2. ارفع محتويات هذا المجلد إلى المستودع.
3. افتح تبويب **Actions**.
4. اختر **Decompile original APK**.
5. اضغط **Run workflow** وانتظر انتهاء المهمة.
6. افتح نتيجة التشغيل ثم نزّل Artifact باسم `exam-editor-25-decompiled`.
7. أعد رفع ملف `decompiled-source.zip` هنا.

## ما الذي ستنتجه المهمة؟
- `apktool/`: موارد Android وملفات Smali وبيانات فك APK.
- `jadx/`: محاولة استعادة شيفرة Java من ملفات DEX.

## الخطوة التالية بعد التفكيك
يجب مراجعة:
- `DatabaseHelper`
- `EnterOneActivity`
- `ExzamVActivity`
- `AndroidManifest.xml`
- مخطط قاعدة البيانات وطريقة ربط السجل `ID` بالسؤال والاختبار.

بعد ذلك يمكن تنفيذ ميزة الصور في الشيفرة الأصلية، مع إضافة جدول صور منفصل وترحيل قاعدة بيانات غير هدّام، ثم بناء APK واختباره.

## تحذير سلامة البيانات
أظهر الفحص الأولي وجود `DROP TABLE IF EXISTS nabeel_table` في نصوص DEX الخاصة بمسار `onUpgrade`. لا ترفع رقم إصدار قاعدة البيانات أو تشغّل ترقية مدمرة قبل فحص هذا المسار وتعديله.

## حالة العمل
لم يتم تعديل APK أو بناء نسخة جديدة بعد. هذه الحزمة تجهز عملية التفكيك على GitHub لأن بيئة الفحص الحالية لا تتضمن APKTool/JADX/Android SDK Build Tools ولا تستطيع تنزيلها مباشرة.
