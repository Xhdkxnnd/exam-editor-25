# محرر الامتحانات 25 — فرع صور الأسئلة

هذا الفرع يضيف إرفاق صور متعددة لكل سؤال إلى APK الأصلي المفكك، مع الحفاظ على بيانات الأسئلة القديمة.

## النطاق المنفذ
- اختيار عدة صور من منتقي Android.
- التقاط صورة بواسطة تطبيق الكاميرا الخارجي عبر `FileProvider`، مع حفظ مسار الملف المؤقت لاستعادته إذا أعاد Android إنشاء الشاشة أثناء التصوير.
- حصر `FileProvider` في مجلد صور التطبيق `Android/data/.../files/Pictures/` بدلاً من كشف جذر التخزين الخارجي.
- نسخ الصور إلى مجلد التطبيق الداخلي `question_images/`.
- تخزين المسارات النسبية في المفتاح الاختياري `images` داخل HashMap السؤال.
- معاينة الصور وحذف صورة منفردة قبل اعتماد التغييرات.
- تأجيل حذف الملفات القديمة إلى ما بعد نجاح `SharedPreferences.commit()`، وتنظيف الملفات الجديدة غير المحفوظة عند الرجوع.
- عرض الصور في محول الصفحة الأولى والصفحة الثانية، ورسم صفحتي PDF إلى صور نقطية.

## التوافق وسلامة البيانات
- لا تعديل على مخطط SQLite أو إصدار قاعدة البيانات أو `DatabaseHelper.onUpgrade()`.
- السؤال القديم الذي لا يحتوي `images` يعامل كأنه يحتوي قائمة فارغة.
- لا يُحذف ملف صورة محفوظ عند حذفها من المعاينة؛ يتم الحذف بعد نجاح حفظ السؤال فقط.
- لم يتغير `main`؛ التطوير مستمر على فرع العمل فقط.
