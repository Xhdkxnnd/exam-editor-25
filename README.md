# محرر الامتحانات 25 — فرع صور الأسئلة

هذا الفرع مخصص لإضافة عدة صور لكل سؤال في APK الأصلي المفكك، مع الحفاظ على بيانات الأسئلة القديمة.

## النطاق الحالي
- اختيار عدة صور من منتقي Android.
- التقاط صورة بواسطة تطبيق الكاميرا الخارجي عبر `FileProvider`.
- نسخ الصور إلى مجلد التطبيق الداخلي `question_images/`.
- تخزين المسارات النسبية في المفتاح الاختياري `images` داخل HashMap السؤال.
- معاينة الصور وحذف صورة منفردة قبل اعتماد التغييرات.
- تأجيل حذف الملفات القديمة إلى ما بعد نجاح `SharedPreferences.commit()`، وتنظيف الملفات الجديدة غير المحفوظة عند الرجوع.
- عرض الصور في محول الصفحة الأولى والصفحة الثانية، ثم رسم صفحتي PDF إلى صور نقطية.

## التوافق وسلامة البيانات
- لا تعديل على مخطط SQLite أو إصدار قاعدة البيانات أو `DatabaseHelper.onUpgrade()`.
- السؤال القديم الذي لا يحتوي `images` يعامل كأنه يحتوي قائمة فارغة.
- لا يُحذف ملف صورة محفوظ عند حذفها من المعاينة؛ يتم الحذف بعد نجاح حفظ السؤال فقط.
- يبقى `main` مستقلاً، ولا تُدمج تغييرات هذا الفرع قبل اختبار APK على جهاز حقيقي.

## حالة التحقق
- اختبارات Python الساكنة تتحقق من نقاط الربط في Smali، حفظ/إلغاء الصور، محولي الصفحتين، ورسم صفحتي PDF.
- يجب أن ينجح GitHub Actions بعد كل تعديل قبل اعتبار APK قابلاً للتجربة.
- البناء الناجح السابق رقم 33 يخص نسخة أقدم من الكود؛ لا يمثل اختبار التعديلات الحالية.
- لم يثبت بعد اختبار الكاميرا والمعرض والطباعة على هاتف فعلي، ولا اختبار عدد كبير من الصور يتجاوز المساحة المتاحة في الصفحة.

## البناء
شغّل Workflow باسم **Build gallery and camera image attachment APK** من تبويب Actions. ينتج APK موقّعاً بمفتاح Debug مؤقت؛ لا يصلح كتحديث فوق APK الأصلي إذا اختلف التوقيع.
